# GOLAZO-APP

אוסף משחקים בקובץ HTML יחיד — פותחים בדפדפן, בלי התקנה ובלי שרת.

| משחק | קובץ | תיאור |
|---|---|---|
| Goaldle | [`goaldle.html`](goaldle.html) | חידון כדורגל יומי — לנחש את המהלך מתוך תרשים המגרש. |
| סיקרט היטלר | [`secret-hitler.html`](secret-hitler.html) | משחק חברתי ל-5–10 שחקנים במכשיר אחד שעובר בין כולם (pass & play). |
| סיקרט היטלר אונליין | [`secret-hitler-online.html`](secret-hitler-online.html) | אותו משחק, כשכל שחקן משחק מהטלפון שלו — חדר עם קוד בן 4 ספרות. |

הגרסה האונליין בנויה ב-React עם עיצוב בסגנון כרזת תעמולה משנות ה-30
ואנימציה לכל אירוע במשחק. כל הספריות והגופנים מתארחים בתיקיית `vendor/`,
כך שאין תלות בשום שירות חיצוני (מלבד שרת התיווך של PeerJS, שדרכו הטלפונים
מוצאים זה את זה). הקובץ `.nojekyll` הכרחי — בלעדיו GitHub Pages מתעלם
מתיקיית `vendor/` והמשחק לא ייטען.

## סיקרט היטלר — איך משחקים

1. פותחים את `secret-hitler.html` בטלפון (אפשר להוסיף למסך הבית).
2. מזינים את שמות השחקנים **לפי סדר הישיבה** (5–10 שחקנים) ומתחילים.
3. המכשיר עובר בין השחקנים: כל אחד רואה את התפקיד שלו בפרטיות ומעביר הלאה.
4. המשחק מנהל לבד את הכול — הצעת קנצלר, הצבעה חשאית, חלוקת קלפי מדיניות,
   כוחות הנשיא (חקירה, הצצה, בחירות מיוחדות, הוצאה להורג), וטו, מד בחירות
   כושלות ותנאי הניצחון.

המשחק נשמר אוטומטית בדפדפן, כך שסגירה בטעות לא הורסת את הסבב.

## סיקרט היטלר אונליין — כל אחד מהטלפון שלו

עובד רק כשהדף מוגש מכתובת אינטרנט (GitHub Pages), לא כקובץ מקומי.

1. שחקן אחד פותח את `secret-hitler-online.html`, בוחר **פתיחת חדר חדש** ומקבל קוד בן 4 ספרות.
2. השאר פותחים את אותו קישור, בוחרים **הצטרפות לחדר** ומקלידים את הקוד.
3. מ-5 מחוברים ומעלה המארח לוחץ **התחל משחק**.

הטלפונים מדברים ביניהם ישירות (WebRTC דרך PeerJS), בלי שרת משלנו ובלי הרשמה.
המכשיר של המארח מנהל את המשחק, ולכן הדף אצלו צריך להישאר פתוח; מי שמתנתק
יכול לחזור לאותו חדר עם אותו קוד ולהמשיך מאותו מקום. החיבור אמין במיוחד
כשכולם על אותה רשת WiFi.

### התקנה למסך הבית

לדף יש `manifest.webmanifest` ואייקונים, כך ש"הוספה למסך הבית" יוצרת אייקון
אמיתי ופותחת את המשחק במסך מלא בלי סרגלי הדפדפן.
